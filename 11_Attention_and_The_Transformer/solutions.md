## Level 1: Recall & Conceptual

### 1. Roles of Query, Key, and Value
- **Query ($Q$)**: "What am I looking for?" Generated by the current token seeking context from other tokens.
- **Key ($K$)**: "What do I offer / what is my address?" Generated by all tokens in the sequence; compared against queries via dot products ($Q K^T$) to calculate relevance weights.
- **Value ($V$)**: "What is my actual content/meaning?" The raw information extracted and weighted by attention scores ($\sum \alpha_i V_i$) to construct the updated contextualized representation.

### 2. Permutation Invariance Without Positional Embeddings
Matrix multiplication and row-wise softmax treat each token row independently. If you shuffle the order of input tokens, the resulting attention weights and output values will shuffle in the exact same permutation without any change to the values computed. Without positional embeddings ($P_i$ or RoPE), a Transformer cannot distinguish between *"the dog bit the man"* and *"the man bit the dog"*.

### 3. Causal Mask in Autoregressive Models
A causal mask is an upper-triangular matrix filled with $-\infty$ above the main diagonal. Because $\text{softmax}(-\infty) = 0$, it zeroes out attention weights to all future positions. This is mandatory for generative LLMs to prevent the model from "cheating" by reading tokens it hasn't generated yet during pre-training.

## Level 2: Hands-On Implementation

### 1. PyTorch Scaled Dot-Product Attention Matching Native Reference

```python
import math
import torch
import torch.nn.functional as F

def scaled_dot_product_attention_custom(Q: torch.Tensor, K: torch.Tensor, V: torch.Tensor, mask: torch.Tensor = None):
    d_k = Q.size(-1)
    # 1. Scaled dot product
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # 2. Masking
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
        
    # 3. Softmax
    weights = F.softmax(scores, dim=-1)
    
    # 4. Value aggregation
    output = torch.matmul(weights, V)
    return output, weights

if __name__ == "__main__":
    torch.manual_seed(42)
    B, H, T, D = 2, 4, 8, 32
    Q = torch.randn(B, H, T, D)
    K = torch.randn(B, H, T, D)
    V = torch.randn(B, H, T, D)
    
    # Custom
    out_custom, _ = scaled_dot_product_attention_custom(Q, K, V)
    # PyTorch reference
    out_ref = F.scaled_dot_product_attention(Q, K, V)
    
    max_diff = (out_custom - out_ref).abs().max().item()
    print(f"Max difference with native PyTorch: {max_diff:.2e}")
    assert max_diff < 1e-5
    print("✅ Scaled dot-product attention verified against reference!")
```

### 2. 2D Rotary Position Embedding (RoPE) Relative Invariance

```python
import math
import torch

def rotate_2d(x: torch.Tensor, m: int, theta: float = 10000.0) -> torch.Tensor:
    """Rotates 2D vector x by angle m * freq."""
    freq = theta ** (-0.0) # For 2D, single frequency = 1.0
    angle = m * freq
    cos_m = math.cos(angle)
    sin_m = math.sin(angle)
    x1, x2 = x[0], x[1]
    return torch.tensor([x1 * cos_m - x2 * sin_m, x1 * sin_m + x2 * cos_m])

if __name__ == "__main__":
    torch.manual_seed(42)
    q = torch.randn(2)
    k = torch.randn(2)

    # Rotate at positions m=5 and n=2 (relative offset = 3)
    q_5 = rotate_2d(q, m=5)
    k_2 = rotate_2d(k, m=2)
    dot_5_2 = torch.dot(q_5, k_2).item()

    # Rotate at positions m=10 and n=7 (same relative offset = 3)
    q_10 = rotate_2d(q, m=10)
    k_7 = rotate_2d(k, m=7)
    dot_10_7 = torch.dot(q_10, k_7).item()

    print(f"Dot product at positions (5, 2):  {dot_5_2:.6f}")
    print(f"Dot product at positions (10, 7): {dot_10_7:.6f}")
    assert math.isclose(dot_5_2, dot_10_7, rel_tol=1e-5)
    print("✅ RoPE relative distance invariance mathematically verified!")
```

## Level 3: Research Deep Dive (Approach & Conceptual Guidance)

### FlashAttention: Hardware Tiling & Online Softmax
- **The Bottleneck**: Standard attention computes $S = Q K^T \in \mathbb{R}^{N \times N}$, writes this giant matrix to GPU High-Bandwidth Memory (HBM), reads it back to compute $P = \text{softmax}(S)$, writes $P$ to HBM, and reads it again to compute $O = P V$. HBM memory bandwidth is ~2 TB/s, while on-chip SRAM cache is ~19 TB/s.
- **Tiling**: FlashAttention partitions $Q, K, V$ into smaller blocks (e.g., $128 \times 128$) that fit entirely into on-chip SRAM cache.
- **Online Softmax**: By tracking running maximums ($m_i$) and running normalizers ($l_i$) incrementally across blocks:
  $$m^{\text{new}} = \max(m^{\text{old}}, \max(S_{\text{block}})), \quad l^{\text{new}} = e^{m^{\text{old}} - m^{\text{new}}} l^{\text{old}} + \sum e^{S_{\text{block}} - m^{\text{new}}}$$
  it updates the accumulated output $O$ without ever materializing or storing the full $N \times N$ attention matrix in HBM.
- **Impact**: Reduces memory IO from $O(N^2)$ to $O(N)$, speeding up attention 2x–4x and allowing context scaling from 2k tokens to 128k+ tokens on standard GPUs.
